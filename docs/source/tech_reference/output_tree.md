## Output Directory Structure

The output directory contains three subdirectories: `region`, `ngen`, and `eval`, which store the output files generated by the regionalization, NGEN simulation, and evaluation steps, respectively. The directory tree below lists up to 10 files per directory; additional files are omitted from the listing.
